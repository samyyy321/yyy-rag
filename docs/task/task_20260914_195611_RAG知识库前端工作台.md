# RAG 知识库前端工作台 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 逐任务执行。本任务使用复选框跟踪状态。

**目标：** 在项目根目录 `app/` 中建立 React + Vite + TypeScript 知识库工作台，覆盖当前 FastAPI 后端的知识库、文档和 RAG 问答接口。

**架构：** 前端使用 React 单页工作台，TanStack Query 管理所有后端资源缓存与失效，组件局部状态只保存选中知识库、表单输入、弹窗和问答设置。所有 HTTP 请求集中于 `src/api/`，异步导入状态轮询独立为 Hook，页面组件不得直接使用 `fetch`。Vite 开发代理把 `/api` 原样转发至后端。

**技术栈：** React、TypeScript、Vite、TanStack Query、原生 CSS、Vitest、React Testing Library、`@testing-library/user-event`、jsdom。

**设计依据：** `docs/spec/spec_20260914_193826_RAG知识库前端工作台.md`
