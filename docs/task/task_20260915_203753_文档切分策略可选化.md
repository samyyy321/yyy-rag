# 文档切分策略可选化实施任务

> **For agentic workers:** 使用 `superpowers:executing-plans` 在当前会话逐任务执行。所有步骤使用复选框跟踪，不开启子代理。

**目标：** 让用户在文档上传时选择递归、滑动窗口或语义切分策略；将选择持久化到文档记录，并在异步离线索引阶段统一执行对应策略。

**架构：** 文档模型保存 `chunk_strategy`，上传接口以 multipart 字段接收策略，后台任务读取持久化值后传入 `ingest_file()`。切分实现集中为独立、可测试的纯函数/异步分发模块，`doc_ingestion.py` 仅负责从 MinerU/LlamaIndex 构造带页码源单元并写入 Milvus。

**技术栈：** FastAPI、Pydantic、SQLAlchemy、Alembic、LangChain Text Splitters、现有 `Embeddings`、pytest。

**规格：** `docs/spec/spec_20260915_202356_文档切分策略可选化.md`

## 全局约束

- [ ] 用户只选择 `recursive`、`sliding_window`、`semantic` 三种策略；不开放任意 chunk 参数输入。
- [ ] 上传未传策略时默认 `recursive`，保持旧客户端兼容。
- [ ] `CHUNK_SIZE`、`CHUNK_OVERLAP`、`SEMANTIC_SIMILARITY_THRESHOLD` 为后端统一配置。
- [ ] 递归与滑动策略使用 overlap；语义策略不复制固定 overlap。
- [ ] 语义切分使用现有 Embeddings，不调用 LLM；其 Embedding 异常使当前异步导入任务失败，不静默切换其他策略。
- [ ] 切分不跨 LlamaIndex 分页源单元合并，保持已有页码语义；MinerU 页码仍为 0。
- [ ] 不修改 Milvus collection schema、分块 ID、向量检索逻辑或重新索引行为。
- [ ] 新增重要模块、函数、类使用中文文档注释；关键策略分支使用中文注释。
- [ ] 测试采用最小 fake Embedding / fake 存储对象，不调用真实模型、MinIO、Milvus、MinerU 或 LlamaIndex。
- [ ] Python 测试、迁移检查和编译使用 Conda `yyy-rag` 环境。
- [ ] 不执行 Git 提交、推送或重置；每个顶级任务完成后更新本文件。

```python
class SourceSegment:
    text: str
    page_number: int

@dataclass(frozen=True)
class ChunkSegment:
    text: str
    page_number: int

async def split_source_segments(
    source_segments: list[SourceSegment],
    *,
    strategy: ChunkStrategy,
    chunk_size: int,
    overlap: int,
    semantic_similarity_threshold: float,
    embedding_model: Embeddings | None,
) -> list[ChunkSegment]: ...
```

**步骤：**

- [ ] 1. 写递归切分失败测试：给定中文段落和句号，输出文本长度不超过 `chunk_size`，优先保留段落/句末边界。
- [ ] 2. 写滑动窗口失败测试：给定固定文本、`chunk_size=6`、`overlap=2`，断言窗口顺序、相邻重叠和无完全冗余尾块。
- [ ] 3. 写语义切分失败测试：Fake Embedding 对相邻单元返回高/低相似度向量，断言低相似度位置形成边界；单一超长语义单元回退递归切分。
- [ ] 4. 写页码失败测试：两个不同 `SourceSegment` 各自切分后，所有输出 chunk 保持对应输入页码，绝不跨页合并。
- [ ] 5. 运行测试，确认 `chunking.py` 不存在。
- [ ] 6. 实现递归策略：使用 `RecursiveCharacterTextSplitter` 和固定中文分隔符列表。
- [ ] 7. 实现滑动窗口：窗口结束即文本末尾时停止；下一起点为 `end - overlap`，步长至少为 1。
- [ ] 8. 实现语义策略：段落优先、无段落时中文句末符号拆分；批量 `aembed_documents()`；计算相邻余弦相似度；低于阈值或到达最大长度时断开；语义单元过长时调用递归策略。
- [ ] 9. 实现策略分发与 `embedding_model=None` 防护：只允许 semantic 要求 Embedding，其余策略不使用它。
