# TruLens 评测目录重构设计

## 目标

将 TruLens 评测运行时实现从 `test/evaluation/` 迁移到 `src/evaluation/`，将实际评测和 Dashboard 启动脚本集中到根目录 `RAG-assessment/`，并将历史及后续 spec/task 文档集中到 `docs/spec/` 与 `docs/task/`。

## 目标结构

```text
src/evaluation/
├── __init__.py
├── trulens_doc_rag_adapter.py
├── trulens_runner.py
└── trulens_dashboard.py

RAG-assessment/
├── README.md
├── run_trulens_evaluation.py
├── run_trulens_dashboard.py
└── data/doc_rag_eval.jsonl

test/evaluation/
├── __init__.py
├── test_trulens_doc_rag_adapter.py
└── test_trulens_storage.py

docs/
├── spec/
└── task/
```

## 边界

- 不修改 `src/query/`、`src/index/`、`src/infra/` 等既有生产 RAG 模块。
- 不改变 TruLens 指标、PostgreSQL 连接和评分策略。
- `RAG-assessment` 是脚本目录，不作为 Python 包导入；入口脚本自行将项目根目录加入 `sys.path`。
- `test/evaluation` 仅保留测试，不保留 TruLens 运行时实现或评测数据。

## 验收标准

1. TruLens 运行时模块位于 `src/evaluation/`。
2. 评测、Dashboard 入口和 JSONL 评测集位于 `RAG-assessment/`。
3. 测试仅从 `src.evaluation` 导入评测实现。
4. spec 文件位于 `docs/spec/`，task 文件位于 `docs/task/`。
5. 编译、评测单元测试和 pytest 收集均通过。
